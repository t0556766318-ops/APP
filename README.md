# APP

Android app with an iPhone-inspired home-screen layout.

## Build

The GitHub Actions workflow in `.github/workflows/build-apk.yml` builds a release APK and uploads it as the `APP-release-apk` artifact.

## App

The first version contains:
- iPhone-style home screen layout
- live clock and date
- app grid and dock
- Hebrew labels and RTL support
- working shortcuts for phone, browser, camera, and settings
